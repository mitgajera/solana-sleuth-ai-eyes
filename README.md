# Solana Sleuth: AI Eyes

## 🔍 Overview

Solana Sleuth: AI Eyes is an advanced blockchain security analytics platform for Solana. The platform provides real-time monitoring, threat detection, and automated security analysis with AI-powered insights.

## ✨ Features

- **Security Dashboard**: Real-time overview of your Solana ecosystem security status
- **Activity Monitoring**: Track suspicious transactions and contract interactions
- **Security Metrics**: Visualize security trends and vulnerabilities over time
- **Data Sources Integration**: Connect to various blockchain data providers
- **Alert System**: Get notified of potential threats and security incidents
- **AI Analysis**: Automated security analysis with ML-powered insights
- **Twitter Integration**: Automatically share security findings via Twitter

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: TailwindCSS with custom cyber theme
- **UI Components**: shadcn/ui with custom cyber styling
- **Backend**: Supabase
- **APIs**: Messari API integration
- **Charts**: Recharts for data visualization 
- **Edge Functions**: Supabase functions for AI analysis and Twitter integration

## 🚀 Getting Started

### Prerequisites

- Node.js (v16+)
- npm or bun
- Supabase account
- Messari API key
